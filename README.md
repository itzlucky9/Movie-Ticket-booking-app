# Movie Ticket Booking App 🎬

A Flutter-based Movie Ticket Booking application with a modern and responsive user interface.

## Features

* Explore movies with detailed information
* Custom Dart models for dynamic data management
* Easy date, time, and seat selection
* Smart seat booking with reserved seat support
* Real-time ticket pricing based on selected seats
* * View selected seats and total ticket price
* Clean, modern, and responsive Flutter UI
